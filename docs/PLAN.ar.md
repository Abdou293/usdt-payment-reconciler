# خطة المشروع (بالعربية)

## الفكرة
نظام يراقب محافظ استلام USDT (مراقبة فقط، بدون مفاتيح خاصة)، يكتشف الدفعات، يربط كل دفعة بطلبها عبر "مبلغ فريد" لكل طلب، ينتظر التأكيدات، يرسل الإشعارات، ويصدر تقارير مطابقة.

## المراحل
1. تجهيز البيئة، فاحص الأسرار (gitleaks)، هيكل المشروع.
2. قاعدة البيانات، آلة حالات الطلب، اختبارات الربط وكل الحالات الصعبة، سلسلة محاكاة.
3. مراقب TRON ومراقب EVM مع الاستئناف من آخر نقطة (cursor)، اختبارات بـ fixtures، ثم تجربة على الشبكة التجريبية.
4. بوت تيليجرام والإشعارات، Webhook موقّع بـ HMAC.
5. لوحة التحكم، تقرير المطابقة، تصدير CSV، صفحة الحالة، وضع العرض.
6. النشر المجاني (Render أو Vercel، وضع العرض فقط) + دليل إعداد لتاجر حقيقي.
7. النشر على GitHub: README، رخصة MIT، إخلاء مسؤولية، دليل Upwork، قائمة فحص أمني نهائية.

## هيكل المجلدات
```
src/core           منطق المبالغ الدقيقة، حالات الطلب، الربط
src/db             قاعدة البيانات (SQLite ← PostgreSQL)
src/chains         المراقبون: tron / evm / simulated
src/services       الطلبات، معالجة الدفعات، التقارير
src/api            REST API
src/bot            بوت تيليجرام
src/notifications  تيليجرام + Webhook
src/workers        حلقة الاستطلاع الدورية
dashboard/         لوحة التحكم (React + Vite) — في المرحلة 5
scripts/           التحقق من عقود USDT، بيانات العرض
tests/             الاختبارات والـ fixtures
docs/              المخططات والتوثيق
```

## قواعد الأمان
- لا مفاتيح خاصة ولا عبارات استرداد ولا كود توقيع إطلاقاً.
- الأسرار في `.env` فقط (مُستثنى من Git)، و`.env.example` فيه أسماء فقط.
- gitleaks يفحص كل commit، وفحص كامل للمجلد والتاريخ قبل كل push.
